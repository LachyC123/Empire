# Verification scope
Run python3 tools/validate_pack.py.

Checks: JSON syntax and ID references; upgrade/recipe dependency cycles; six ranks per branch and increasing prices; visible/mechanical effect fields; property/event/caper unlock references; four opening sales and first hire affordability; baseline net margin; packaging speed formula; a finite-input three-stage production fixture with one versus two packers and faster assembly; item conservation at every fixture tick.

The fixture excludes physical travel, orders/demand, commissions during simulated jobs, worker pathfinding, full progression balance, art, actual controls and browser behaviour. Those require the implementation milestones. No playable game, visual asset generation, repository change or physical iPhone test is claimed by this pack.
